# 🧪 QA Advanced Portfolio - API & SQL Testing Project

## 📌 Project Overview

This project is a Quality Assurance (QA) portfolio that demonstrates manual API testing, data validation, bug reporting, and test design skills using ReqRes API and Postman.

The objective of this project is to simulate real QA activities including:
- API testing
- SQL-style data validation (via API responses)
- Bug reporting
- Test scenario design
- Edge case analysis

This project showcases both test execution and test design skills.

---

## 🛠️ Tools Used

- Postman (API Testing)
- GitHub (Documentation & Version Control)
- ReqRes API (Mock API for testing)
- Markdown (Documentation)
- Manual Testing Techniques

---

## 🌐 API Testing Scope

The API testing part covers the following areas:

### 🔹 User Management (CRUD Operations)
- Create User (POST)
- Retrieve User (GET)
- Update User (PUT / PATCH)
- Delete User (DELETE)

### 🔹 Validation Testing
- Email format validation
- Missing required fields
- Empty request body handling
- Null value handling

### 🔹 Error Handling
- Invalid JSON requests
- Non-existing user ID handling
- API response validation

---

## 🗄️ SQL / Data Validation Scope

Although no real database was used, data validation was performed through API responses.

This includes:
- Verification of returned user data consistency
- Validation of required fields
- Checking data integrity in API responses
- Observing system behavior with invalid or incomplete data

---

## 🐞 Bug Reporting

The project includes 3 documented API bugs:

- BUG-001: Invalid email format accepted during user creation
- BUG-002: Empty request body accepted
- BUG-003: Missing required email field accepted

Each bug report includes:
- Steps to reproduce
- Expected vs actual result
- Severity & Priority classification
- Evidence (screenshots)
